# ExerGen Presentation Website

Welcome to the **ExerGen** static-site repository. This website serves as the central hub for our COMP 3350 final project presentation, showcasing the vision, architecture, and development journey of our Android fitness application.


---

## 🏋️ Project Vision
ExerGen is an offline Android application designed to eliminate "gym-paralysis." It generates structured interval workouts tailored to available equipment, target muscle groups, and time constraints, then guides users through every set with a live interactive timer.

## 🚀 Quick Start
Open `website/index.html` in any modern web browser. 
*No build tools, compilers, or local servers are required.*

## 🛠️ Major Features Highlighted
*   **Workout Builder:** Algorithmic routine generation based on constraints.
*   **Live Workout Mode:** Interactive timer with exercise animations and audio cues.
*   **Statistics Dashboard:** Visual trends of calories burned and session frequency.
*   **Exercise Library:** Searchable database of 30+ exercises with instructions.
*   **Session History:** Local persistence of every completed workout.
