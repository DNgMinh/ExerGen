If conflict arises or expectations are not met, we agree to follow this process **in order**:

- Chat on one on to resolve the problem
- Open discussion to team for help and mediation
- Ask professor for help!

How will concerns be raised respectfully?

All of us have come to the consensus that there's nothing personal, and that we all want to succeed both in the project and in the course. As peers, we will do our best do communicate respectfully and ensure our ideas are heard.

**8\. Responsible GenAI Use**

As a team, we have discussed the responsible and ethical use of Generative AI tools (e.g., ChatGPT, Copilot) for this project. We agree on the following shared norms:

Allowed uses of GenAI in this project include:  
• Code quality  
• Documentation (e.g., README)

Disallowed uses of GenAI in this project include:  
• Entire features or complete copy/past with no review

Key risks we have identified related to GenAI use (e.g., correctness, over-reliance, fairness, integrity):  
• Over-reliance or hallucinations

How our team will ensure transparency, accountability, and shared understanding of AI-assisted work:  
• By documenting and notifying the group chat when and where we have used GenAI

• Ensure we can explain the code and understand what's happening across the projet
